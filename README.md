# Flee

Meta Quest 2를 대상으로 개발한 VR 3D 공포 탈출 게임입니다.  
플레이어는 제한된 공간에서 몬스터의 추격을 피하며 단서를 찾고 탈출합니다.

[게임 시연 영상](https://www.youtube.com/watch?v=SI19YiiQx5M)

## 프로젝트 정보

| 항목 | 내용 |
| --- | --- |

| 언어 | C# |

## 성과

- 학과 졸업작품 전시회 최우수상
- 대학교 캡스톤 디자인 경진대회 장려상

## 담당

- Main Monster AI
- 인트로·조우·사망 Timeline 연출
- PC 기반 상호작용·UI의 VR 전환
- 기능 통합 및 전체 플레이 흐름 점검

## 주요 구현

### 몬스터 추격 AI

- PATROL, CHASE 상태를 분리해 몬스터 행동 구성
- 거리·시야각·Raycast를 모두 만족할 때만 플레이어 추격
- 플레이어가 은신하거나 일정 거리 이상 벗어나면 순찰 상태로 복귀

### 조우·사망 연출

- Timeline으로 몬스터 이동·충돌 제어, 카메라·GameOver UI·글리치 효과 재생
- 인트로에서 몬스터 등장, 카메라 흔들림, 게임 진입 흐름 구성

### VR 상호작용·UI 전환

- 카메라 중심 상호작용을 오른손 컨트롤러 Raycast 방식으로 변경
- 왼손 컨트롤러 충돌을 이용한 손전등 획득과 손 애니메이션 전환
- UI를 World Space로 배치하고 VR 카메라를 Event Camera로 지정
